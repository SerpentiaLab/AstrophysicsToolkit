# AstrophysicsToolkit

*A scientific C++ library for stellar astrophysics.*

The project combines theoretical astrophysics with scientific software development.

AstrophysicsToolkit is a personal project for studying stellar astrophysics through scientific theory and programming in C++.

## Objectives

- Strengthen foundations in stellar astrophysics.
- Learn C++.
- Develop reusable scientific tools.
- Connect physical equations with algorithms.

## Current Modules

- Physical and astronomical constants.
- Length unit conversions.

## Technologies

- C++20
- CMake
- Git
